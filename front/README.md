# Front

## Pré-requis

Pour accéder aux Map dans l'application vous devez créer votre google_maps_api_key : 

https://console.cloud.google.com/projectselector2/google/maps-apis/credentials?utm_source=Docs_CreateAPIKey&utm_content=Docs_maps-backend&_gl=1*1x5dkmp*_ga*NDA4NzExNjI4My4xNzEwMjUyODMz*_ga_NRWSTWS78N*MTczMDIyMzM1NC4xLjEuMTczMDIyMzQxNS4wLjAuMA..&pli=1

Renseigner votre clé dans le fichier /front/src/views/configurations/MapConfiguration.js

## Lancer l'application

Pour lancer l'interface graphique, lancer la commande suivante dans le dossier front : 

```
npm install
npm run start
```
